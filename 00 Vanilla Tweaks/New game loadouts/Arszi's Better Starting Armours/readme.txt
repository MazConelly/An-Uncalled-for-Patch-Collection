-Explanation:
DLTX conversion.

Small tweaks. The original mod only worked for CSky, Duty, and Ecologs.

Ecologs will now start with the ISRIT guard jumpsuit, instead of the basic SSP-99. Even the basic SPP gives you a huge edge on artefact hunting, and a new eco player probably wants something to survive attacks instead.
Now loners will start with the Firearm enthusiast's jacket, as a small boost over the eternal novice jacket.
